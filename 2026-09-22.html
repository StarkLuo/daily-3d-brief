01 · DIRECT HIT

VoxelTTO

Feed-forward 3DGSVoxel-alignedTTO

解决什么：像素级回归会制造重叠 Gaussian 与伪影，位姿误差又会破坏新视角对齐。

怎么做：多图特征先聚合进全局体素，再解码 Gaussian；相机先验可驱动轻量 LoRA 测试时优化，并用 stochastic solid volume rendering 加强几何监督。

关键判断：本轮最直接对应前馈 3DGS 的工作，但属于“前馈骨干 + 可选 TTO”的混合路线。

02 · CROSSOVER

FOCAL-VLA

VLAVGGT DistillationImplicit WM

解决什么：2D VLA 缺乏空间与时间理解，而全场景几何和未来预测又带来大量任务无关信息。

怎么做：只在当前子任务相关区域蒸馏 VGGT 几何，并用 Track4World 当前/未来特征监督隐式 3D 演化；推理时移除两个昂贵 teacher。

关键判断：形成“前馈几何 teacher → 隐式 4D world representation → VLA action”的清晰路线。

表征在变Pixel-aligned → voxel / persistent world memory。
系统在变一次前向 → 前馈初始化 + 选择性自适应。
下游在变可渲染重建 → action-relevant 3D / 4D token。

03 · SYSTEM DESIGN

Adaptive World Memory 3D Foundation Model

把持续记忆、机器人定位、稠密点云与 Gaussian rendering 合并进一个长期在线系统。

Persistent MemoryGaussian HeadSLAM Backend
核心结构：transformer gated update + 时空一致性调节 token 的更新与遗忘。
扩展机制：local submaps、tracking、loop closure 与基于 SL(4) 的全局 refinement。
研究价值：展示前馈 3D 表征如何升级为 persistent robotic world representation；并非纯单次前向。
ONLINE ADAPTATION

Info3R

根据新帧的信息量调制状态更新；累计更新幅度与置信度共同触发动态 reset，再用 anchor-to-world alignment 接回全局坐标。

看点：从“每帧等量更新”转向显式评估帧价值与状态饱和。

MEMORY EFFICIENCY

LoG-VGGT

少量 block 做跨窗口 attention，全局 camera token 再与紧凑 register token 交互，兼顾显存与长期位姿一致性。

看点：前馈长序列重建的工程重点已转向跨窗记忆与全局相机精修。

FAIL-FAST SLAM

Noctif3R

面向极暗、单目与嵌入式硬件，以显式 match gate 在不可观测时停止输出，并拆分 tracking 与建图分辨率。

看点：对事件视觉的启发是把“何时拒绝重建”做成系统能力。

DYNAMIC 4DGS · SIGGRAPH ASIA TC*

4DGS-Fixer

以多视图深度改善初始化，再沿新轨迹渲染视频，用扩散修复结果反复回灌 4DGS，补全未观测区域。

看点：“前馈初始化 + 生成先验精修”的上界参考；迭代成本需单列。

ECCV 2026 · OFFICIAL LIST

Cube-Splat

把 360° 图像分成共享光心的虚拟 pinhole view，在单一主位姿上聚合多视面梯度并优化 anisotropic Gaussians。

定位：优化式 GS-SLAM，不是前馈核心；但会议状态已由官方列表核验。

CROSS-EMBODIMENT ACTION

GALA

以统一 3D 末端运动表示对齐人手与灵巧手，联合 visual latent action 和 geometric latent action 监督 VLA 预训练。

定位：不含场景重建，但值得借鉴其跨 embodiment 的几何动作接口。

GaussianFactory单次扫描重建可编辑 3DGS，再批量生成机器人示范；展示 GS 作为 embodied data factory 的工程价值。
事件相机邻近项昆虫双目事件相机工作恢复三维目标轨迹，另有事件地点识别；均不是场景表面或辐射场重建。
状态口径除 Cube-Splat 外均按 arXiv 预印本处理；4DGS-Fixer 的接收状态目前来自 arXiv comments。
